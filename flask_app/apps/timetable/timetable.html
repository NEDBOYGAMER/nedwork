Tips & shortcuts

  • Click an empty slot → new block. It uses the last type you picked, snapped to that type's usual start minute and default length.
  • Drag a block to move it (day + start — the duration stays), drag its bottom edge to resize. Multi-day blocks are time-shifted; change their days in the editor.
  • Multi-day blocks: in the block editor, click the day chips to put one block on any combination of days (e.g. a commute Mon/Wed/Fri).
  • Right-click a block → Edit · Duplicate · Copy to day… · Delete.
  • Right-click a timetable tab → Rename · Duplicate · Copy from another timetable… · Delete.
  • ⋯ in a day header: copy that whole day to another day, or clear it.
  • “Repeats” makes a block appear only on odd/even ISO weeks — the week selector on top filters the view.
  • ⚙ Settings holds the theme, grid size, week range and the Types editor (color, emoji, start :MM, default length).
  • ⬇ Export: .ics for Google/Apple/Outlook, JSON backup, import, print.
