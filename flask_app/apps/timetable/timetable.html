Tips & shortcuts

  • Click an empty slot → new block. It uses the last type you picked, snapped to that type's usual start minute and default length.
  • Drag a block to move it (day + start — the duration stays), drag the bottom edge of the last segment to resize.
  • Splitting is per type (⚙ Types): long blocks are divided into a period/break rhythm (e.g. V & U: 45 min + 15 min pause). The pauses are filled in with the same color, so the whole unit reads as one block; each segment shows its own time — on mobile the segments and pauses are listed on the card.
  • Past midnight: a sleep time before the wake time counts as the next day (wake 08:00, sleep 01:00). The grid hatches only the hours inside the visible day.
  • Custom color: every block can override its type color in the editor — and ⟲ from same copies the color of the last block with the same name & type (also in the right-click menu as “Color from same”).
  • Multi-day blocks: click the day chips to put one block on any combination of days (e.g. a commute Mon/Wed/Fri).
  • Right-click a block → Edit · Color from same · Duplicate · Copy to day… · Delete. Right-click a timetable tab → Rename · Duplicate · Copy from · Delete.
  • ⋯ in a day header: copy that day to another day, or clear it.
  • ⚙ General: theme, style, grid size, week range and wake & sleep — sleep times are saved per timetable.
  • ⚙ Types: color, emoji, start :MM, default length, opacity, split rhythm.
  • ⚙ Periods: hatched daily windows (“At school”, “At home”) with color, emoji, opacity and per-day overrides — the row's start/end mirror the days (earliest start → latest end) and editing them sets every day. Blocks inside them carry the period icon. Also saved per timetable.
  • ⚙ Stats: choose which chips show (per type, custom groups, periods, avg sleep, total, count, busiest day).
  • ⬇ Export: .ics, PDF (landscape & portrait), PNG image (dark/light), JSON backup, import, print.
  • On mobile: tap ✏️ to enter edit mode (nothing can be changed before that), the red line shows where you are in the day, swipe between days, ☰ holds everything else.
  • The hint bar at the bottom only appears while this schedule has no blocks yet — all of it lives here.
